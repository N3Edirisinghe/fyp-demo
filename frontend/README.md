# AffetX Web Front-End

Production-ready, zero-dependency, ultra-minimalist web front-end for the **AffetX** Final Year Research Project.

## Directory Structure

```
frontend/
├── index.html       # Main Web Entrypoint
├── css/
│   └── styles.css   # Executive Minimalist Stylesheet
└── js/
    └── main.js      # Interactive Modal & AI Companion Logic
```

## How to Run

Double-click `index.html` or open it with any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
