# Trained Model Weights (not committed to git)

This folder holds trained model weights, generated by the notebooks in
`training/notebooks/`. It is empty in a fresh clone by design — see
`.gitignore`.

## Expected contents after training

```
models/
├── voice_emotion/
│   ├── cnn_lstm.pt                     # from train_voice_emotion_cnn_lstm.ipynb
│   └── wav2vec2_finetuned/             # from train_voice_emotion_wav2vec2.ipynb
│       ├── config.json
│       ├── model.safetensors
│       └── preprocessor_config.json
└── text_emotion/
    └── distilroberta_finetuned/        # from train_text_emotion_distilroberta.ipynb
        ├── config.json
        ├── model.safetensors
        └── tokenizer files...
```

## Where to get these

1. Run the three notebooks in `training/notebooks/` on Google Colab (free GPU).
2. Download the resulting weights and place them in the matching subfolder here.
3. For large HuggingFace-format models (Wav2Vec2, DistilRoBERTa), consider
   pushing them to the **HuggingFace Hub** (free public model hosting)
   instead of committing them to this repo, and pointing
   `config/settings.py` at the Hub model ID instead of a local path — this
   avoids GitHub's file size limits entirely.

Do not commit real model weight files to git — they are large binary
files and don't belong in version control history. Use Git LFS or the
Hugging Face Hub instead.
