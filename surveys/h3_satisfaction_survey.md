# H3 Survey: Overall User Satisfaction

Administered at the end of **Session 2** (integrated system) and
**Session 3** (conventional memoryless baseline, same LLM), using
identical items for a paired comparison (Section 5.5).

> As with the H2 survey, replace these placeholder items with a validated
> user-satisfaction scale before the real study.

**Scale:** 1 = Strongly Disagree, 5 = Strongly Agree

1. Overall, I am satisfied with this interaction.
2. This assistant felt more helpful than a typical AI assistant.
3. I would want to use this system again.
4. This interaction felt natural and easy.

## Administration Notes
- Sessions 2 and 3 should happen back-to-back in the same visit where
  possible, to minimize time-related confounds between the two conditions.
- Counterbalance order where feasible (some participants do Session 3
  before Session 2) if your team has capacity — note in your limitations
  section if you do not, since order effects are a plausible confound
  otherwise.
